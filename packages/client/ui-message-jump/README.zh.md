# @deepseek-ai/dsh-client-ui-message-jump

[English](README.md) | 中文

消息定位插件（浏览器端部分）：在会话头部 `conversation.session.header.actions` 放置一个导航控件，让对话滚动在用户自己发出的消息之间跳转——即 Codex 风格的「我上一句说了什么」定位。它以用户库插件的形式发布（通过 `dsh plugin add` 安装进 profile，从不作为 `web-app` bundle 行），因此插件管理器将其归类为「库 / library」。

控件是一排编号格子，每个格子对应一条你自己发出的消息，一次最多显示 5 个：消息更多时，在控件上滚动鼠标滚轮即可前后翻动可见窗口（不会带动下方对话滚动）；鼠标悬停或键盘聚焦某个格子时，气泡预览那条消息的文本（无文本块的图片等消息显示占位文案）；点击格子把对话滚动定位到对应消息行。当前位于对话可视区顶部的消息格子高亮，且当它滚出可见窗口时窗口会自动跟随。普通用户消息与进行中的 steering 消息计入，注入的 `context` 不计入。格子列表来自框架 `useSession` 钩子暴露的实时聊天快照，跳转目标来自聊天视图所拥有的 `[data-conversation-scroll]` 滚动容器内已渲染的流式行——头部是该滚动容器的兄弟节点，因此跳转是对滚动位置的直接写入，中间不经过任何会话服务；点击后滚动容器会把目标消息定位到顶部边缘略下方，高亮跟随滚动容器的 scroll 事件更新。

本插件不持有会话状态、不建立刷新链：它只读取聊天快照并滚动滚动容器。会话没有用户消息时不渲染任何内容。由于它只滚动聊天视图已渲染的流，当非聊天视图（例如轨迹视图）处于激活状态时，控件为空操作——此时用户消息行根本不在 DOM 中。

## Model Experience

无模型可见影响。控件只读取已经组装好的聊天快照，并仅写入浏览器滚动位置；不产生任何提示内容、请求或会话事件。

#### KV Cache effect

无——不发请求，因此不影响提供方侧的缓存复用。

## Known Limitations and Deferred Work

- **要求聊天视图已挂载** — 跳转目标是聊天流式行，因此离开默认的 Chat 视图后没有可滚动的内容；控件退化为空操作，而不是强制切换视图。
- **仅在已加载的窗口内工作** — 尚未通过 `loadOlder` 加载的更早页面不计入、也无法跳转。
