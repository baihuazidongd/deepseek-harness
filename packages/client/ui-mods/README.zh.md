# @deepseek-ai/dsh-client-ui-mods

[English](README.md) | 中文

插件页：Loader 条目启用状态的一级管理表面。浏览器插件注册一个 `sidebar.footer.action` 条目（id `mods`）—— 即侧边栏底部设置旁的触发行 —— 并打开全视口管理面板。面板列出每个非 group 的 Loader 条目，带根 Fiber 状态点与一个启用开关，另有两组筛选 chips —— 状态（全部/已启用/已停用）与来源（全部/原生插件/库），各带计数 —— 以及按模块名与条目 id 的搜索。点击条目展开明细块：包声明的描述、版本、完整模块标识、loader 条目 id 与来源分类（`native` = 安装自带 bundle 提供的行，`library` = 用户安装进 profile 的包；Host 无法分类的条目显示为未知，缺失的事实渲染为破折号）。读写都经由生成的 [`pluginInventory`](../../host/plugin-inventory/README.md) Remote：`list` 取快照，`setEnabled` 处理开关翻转，其返回的快照是权威 —— 写入被拒时行会回滚并升起面板级错误行，而不是留下过期的乐观状态。在 Host 侧，写入以显式行持久化到 profile 用户 patch 层，并经启动 patch 监视器热生效，因此开关状态在重启后保留。

触发行与面板沿用设置外壳的模式：触发行匹配侧边栏底部的紧凑节奏（宽行与轨道圆形图标），面板为遮罩加对话框的覆盖层，支持 Escape、遮罩点击与标题栏关闭三条关闭路径，进入时基线焦点落在关闭按钮上。加载、空、无匹配、通用失败（可重试）与写入失败状态都留在挂载组件内部，不暴露传输细节。

## 模型体验

无，本包仅可视化与管理 Host 组合状态；开关可能改变会话组合携带的插件集合，各受影响插件自行说明其模型影响。

#### KV Cache 影响

无；本包不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **每次打开或重试只取一份快照** —— 面板不订阅 Loader 变化，重连后也不自动刷新；重新打开会取新快照。
- **明细仅为包声明的事实** —— 明细块展示包自身 `package.json` 的事实；条目配置值、来源层与失败堆栈推迟。
- **镜像测试与更新流程推迟** —— 插件管理器路线图（镜像实例测试阶梯、晋升门禁、本体更新流程）在后续阶段落地；本包是管理基座。
